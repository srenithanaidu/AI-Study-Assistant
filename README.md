# AI Study Assistant 🤖

AI Study Assistant is an AI-powered educational web application designed to help students understand academic concepts in a simple and student-friendly way.

## 🚀 Live Demo

https://ai-study-assistant-wk1z.onrender.com

## ✨ Features

- 🤖 AI-powered study assistance
- 💬 Ask questions and get instant answers
- 📚 Chat history using SQLite
- 🧹 Clear chat functionality
- 📝 Markdown-formatted AI responses
- 🎨 Modern and responsive user interface
- 🕷️ Animated Spider-Man design
- 🌐 Accessible through a public web link

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask
- SQLite
- Google Gemini API
- Render
